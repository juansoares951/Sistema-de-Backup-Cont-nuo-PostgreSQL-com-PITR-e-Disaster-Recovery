# Sistema-de-Backup-Cont-nuo-PostgreSQL-com-PITR-e-Disaster-Recovery
Implementação de uma solução completa de backup contínuo para PostgreSQL 17 utilizando WAL-G, Backblaze B2, Zabbix e Grafana. O projeto contempla backups FULL automatizados, arquivamento contínuo de WAL, recuperação Point-in-Time Recovery (PITR), políticas de retenção, monitoramento preventivo e alertas
